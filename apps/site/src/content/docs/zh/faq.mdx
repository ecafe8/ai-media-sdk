# 常见问题

## API Key 应该配置在哪里？

两种场景不同：

- **本站 Playground**：Key 保存在浏览器 localStorage（右上角"API 设置"），由浏览器直接发送给 Provider，不经过任何服务器。请勿在不受信任的设备上使用。
- **集成开发**：Key 应保存在你的服务端（环境变量或密钥管理），由服务端调用 SDK；不要把 Key 下发到浏览器。

## 浏览器直连 Provider 报 CORS 错误怎么办？

浏览器直连第三方 API 受同源策略约束，Provider 端点必须允许跨域（返回 CORS 响应头）才能在浏览器中调用。各 Provider 支持程度不同：

- 阿里云：工作空间端点（`*.maas.aliyuncs.com`）可能不允许跨域，请改用标准端点 `https://dashscope.aliyuncs.com/api/v1`。
- 其他 Provider：以端点实际 CORS 行为为准。

解决方向：换用支持 CORS 的端点；或改为服务端代理调用（推荐生产方案）。本站 Playground 能跑通即代表该端点当前支持浏览器直连。

## 结果 URL 过期了怎么办？

Provider 返回的结果 URL 是临时链接（通常数小时至数天）。处理原则：

- 拿到结果后立即下载转存到自有存储（服务端集成）；
- 站点 Playground 可在结果面板选择本地目录自动保存；
- 不要把临时 URL 当作最终资产写入业务数据库。

详见[结果结构](/docs/results)。

## 异步任务轮询超时或想中止怎么办？

`TaskHandle.wait()` 默认 600 秒超时、15 秒轮询间隔：

- 超时抛出 `SdkError`（`TIMEOUT`）。视频任务可按需调大 `timeoutMs`。
- 传入 `signal: abortController.signal` 可在轮询间隙中止等待。
- 任务已在 Provider 侧提交：中止 `wait()` 不会取消远端任务，重新以相同 `taskId` 构造 handle 可继续查询。

## 报 UNKNOWN_MODEL 怎么排查？

`UNKNOWN_MODEL` 表示模型 id 不在该 Provider 的注册表中：

1. 核对模型 id 拼写与各 Provider 页的模型表（站点模型数据直接来自注册表，可作为准绳）。
2. Azure 的 deployment 名称是用户自定义的：内置注册表只有 `gpt-image-2`，其他 deployment 需先用 `createAzureModel` / `provider.createModel` 注册，见 [Azure OpenAI](/docs/providers/azure-openai)。
3. 用 `provider.listModels()` 打印当前注册表确认。

更多错误码含义见[错误处理](/docs/error-handling)。
