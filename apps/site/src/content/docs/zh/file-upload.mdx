# 文件上传

图像/视频生成的输入需要是 Provider 可接受的 URL（或 base64）。本地文件可借助 `@ai-media/uploader` 上传为**临时 URL** 再传入。

> **定位**：uploader 是开发/测试便利工具。各平台临时 URL 均有有效期与配额限制，**生产环境请使用自有持久存储**。

## 两条上传链路

| 链路 | 产物 | 适用 |
| --- | --- | --- |
| `createAliyunUploader`（DashScope） | `oss://` URL | 阿里云百炼图像/视频输入 |
| `createGoogleUploader`（Gemini Files API） | 标准 `https://` URL | 需要公网 https 输入的场景 |

## 工作流示例（Aliyun）

```ts
import { createAliyunUploader } from "@ai-media/uploader/aliyun";

const uploader = createAliyunUploader({ apiKey: "<your-dashscope-api-key>" });

const uploaded = await uploader.upload({
  model: "qwen-image-2.0-pro", // 必须与下游生成调用的模型一致
  filePath: "./input.png", // 或 fileBytes + fileName
});

console.log(uploaded.url); // oss://...（48 小时后过期）
```

三步流程：获取上传凭证 → OSS 直传 → 返回 `oss://` URL。

## 与 editImage 集成

```ts
import { createAliyunBailianProvider } from "@ai-media/provider-aliyun-bailian";
import { editImage } from "@ai-media/sdk";

const provider = createAliyunBailianProvider({
  apiKey: "<your-dashscope-api-key>",
});

const result = await editImage({
  model: provider.image("qwen-image-2.0-pro"),
  prompt: "把画面改成雪天",
  images: [{ url: uploaded.url }],
});
```

`oss://` URL 需要下游请求携带 `X-DashScope-OssResourceResolve: enable` 请求头；使用 `@ai-media/provider-aliyun-bailian` 时适配器会**自动注入**，无需手动处理。

## 注意

- 临时 URL 会过期（Aliyun 48 小时；Google 48 小时自动删除），只适合作为一次性输入。
- 上传产物 `UploadedFile` 的 `requiresHeaders` 声明了下游需要的请求头，换用其他调用方式时请遵循。
- 完整配置字段、`UploadedFile` 形状与 `UploaderError` 错误码见 [uploader 参考](/docs/uploader)。
